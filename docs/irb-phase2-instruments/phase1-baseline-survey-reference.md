# Phase 1 "Student Demographics Survey (Therapy)" — scraped from Qualtrics builder 2026-09-02
(SV_e3dRBIcxM0ne3ga; 371 responses; used for Phase 2 inspiration)

Flow: study-arm selector (online vs SONA) → arm-specific consent (full text incl. mandatory-reporting language) → statement of consent (skip-to-end on decline; signature for SONA arm) → 18+ gate (skip-to-end) → US-location gate (skip-to-end) → user ID (SONA arm) → main block.

Main block questions:
- Therapy duration (never/<1mo/.../5+yrs) with skip for never-participants
- Number of therapists engaged
- Conditions/symptoms list (13 categories + other + prefer not to respond)
- Open: what does "effective" therapy mean; what makes a therapist effective; how well experiences met definition (5-pt); limitations/challenges with human therapists (open; hypothetical variant for never-participants)
- Demographics: sex, age slider (18-65), ethnicity multi, English proficiency
- Stigma: community view of therapy (5-pt + not sure), family view (same)
- Barriers matrix (language, costs, scheduling, fit, trust, cultural understanding) x (not/slight/moderate/significant/very significant)
- Ease of confiding (5-pt); ability to afford therapy (3 options)
- AI familiarity (4 levels); AI-attitudes matrix (comfortable discussing, trust with data, helpful advice, open to multiple sessions) x 5-pt agree
- Extra-credit code block (IS 201); End: SONA credit redirect with embedded id field
